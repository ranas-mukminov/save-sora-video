Chrome Web Store 提交指南
========================

1. 开发者控制台: 访问 https://chrome.google.com/webstore/devconsole/

2. 创建新项目: 点击"添加新项目"

3. 上传文件: 上传 build/chrome-mv3-prod.zip 文件

4. 填写信息: 使用上述描述内容填写以下字段:
   - 扩展名称: Sora Video Downloader
   - 简短描述: 使用上述简短描述
   - 详细描述: 使用上述详细描述
   - 关键词: 使用上述关键词列表
   - 类别: Productivity
   - 语言: 选择中文和英文

5. 截图要求: 准备以下截图:
   - 扩展图标 (128x128px)
   - 弹出窗口界面截图
   - 在Sora页面上的使用效果截图
   - 下载功能演示截图

6. 隐私政策: 需要提供隐私政策链接，说明扩展收集的数据类型

7. 审核: 提交后等待Google审核，通常需要1-3个工作日

注意事项:
- 确保所有描述内容符合Chrome Web Store政策
- 避免使用"破解"、"绕过"等敏感词汇
- 强调扩展的合法性和用户价值
- 提供清晰的使用说明和权限解释
