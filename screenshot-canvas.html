ℹ️ Instructions

  • Select a screenshot using the dropdown below
  • Choose background colors for each canvas
  • Click "Update Canvas" to refresh the display
  • Click "Save as PNG" to download 24-bit PNG images
  • Important: To avoid CORS issues, run a local server first (see below)

🚀 Local Server Setup

To enable PNG export functionality, run one of these commands in your terminal:

  • Python 3: python -m http.server 8000
  • Python 2: python -m SimpleHTTPServer 8000
  • Node.js: npx serve .
  • PHP: php -S localhost:8000

Then open: http://localhost:8000/screenshot-canvas.html
