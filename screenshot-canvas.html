ℹ️ Instructions

  • Select a screenshot using the dropdown below
  • Choose background colors for each canvas
  • Click "Update Canvas" to refresh the display
  • Click "Save as PNG" to download 24-bit PNG images
  • Important: To avoid CORS issues, run a local server first (see below)

🚀 Local Server Setup

Run the Dockerized server to enable PNG export functionality:

  • Docker Compose: ./start-server.sh (or docker compose up screenshot-server)

Then open: http://localhost:8080/screenshot-canvas.html
